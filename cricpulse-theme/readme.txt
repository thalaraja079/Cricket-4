== Description ==
A complete WordPress theme for Cricket Live Scores, Upcoming Fixtures, Points Table, and Leaderboards in Tamil and English.

== Installation in WordPress (வேர்ட்பிரஸ் நிறுவும் முறை) ==

முறை 1 (WordPress Admin Dashboard மூலம்):
1. WordPress Admin Dashboard-ல் நுழையவும்.
2. இடது மெனுவில் Appearance (தோற்றம்) -> Themes (தீம்கள்) செல்லவும்.
3. மேலே உள்ள "Add New Theme" (புதிய தீம் சேர்) பட்டனை அழுத்தவும்.
4. "Upload Theme" பட்டனை அழுத்தி cricpulse-theme.zip கோப்பை தேர்வு செய்யவும்.
5. "Install Now" (இப்போது நிறுவு) கொடுத்து "Activate" செய்யவும்.

முறை 2 (Page Template மூலம் பயன்படுத்த):
1. Pages -> Add New செல்லவும்.
2. வலதுபுறம் உள்ள Page Attributes-ல் Template என்பதை "Cricket Live Scores Full-Width" என தேர்வு செய்து Publish செய்யவும்.

முறை 3 (Shortcode மூலம் பயன்படுத்த):
எந்தவொரு பக்கத்திலும் [cricpulse_live] என உள்ளிட்டால் முழு நேரலை ஸ்கோரும் தோன்றும்.
